# Task 5 — Publish Generated C++ API Reference

## Goal

Replace the current API Reference placeholder page with a production-quality autogenerated C++ API reference pipeline and published output.

## Scope

- Define and document the canonical API generation toolchain (Doxygen as baseline; optional Breathe/Sphinx bridge if needed later).
- Generate API docs from public headers under `include/a2a/**`.
- Add a repeatable local generation command and CI workflow job for validation.
- Publish generated API output as part of the docs website deployment.
- Integrate navigation so mdBook users can discover API docs from the main docs experience.

## Deliverables

- A committed API generation configuration (`Doxyfile` or equivalent) scoped to public SDK surface.
- A docs build step that validates API generation in CI.
- Published API reference accessible from the docs website.
- Updated contributor docs describing how to regenerate API docs locally.

## Acceptance Criteria

- `book/src/api-reference.md` no longer presents placeholder-only guidance.
- Generated API docs include core client, server, transport, and auth public interfaces.
- CI fails when API generation breaks.
- Documentation navigation contains a stable link path to generated API pages.

## Out of Scope

- Full redesign of mdBook theme or information architecture outside API docs integration.
