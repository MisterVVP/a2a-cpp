# Third-party dependencies

The project resolves third-party libraries through its build dependency
mechanism and does not vendor their source code.

| Dependency | Use | License |
|---|---|---|
| simdjson | Private JSON validation and top-level value location | Apache-2.0 |

simdjson is used under its Apache-2.0 licensing option. Its types are not part
of the public A2A C++ API. The a2a-cpp project remains licensed under
Apache-2.0.
