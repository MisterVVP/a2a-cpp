# How to contribute

We'd love to accept your patches and contributions to this project.

## Contribution process

### Code reviews

All submissions, including submissions by project members, require review. We
use GitHub pull requests for this purpose. Consult
[GitHub Help](https://help.github.com/articles/about-pull-requests/) for more
information on using pull requests.

### Contributor Guide

You may follow these steps to contribute:

1. **Fork https://github.com/MisterVVP/a2a-cpp repository.** This will create a copy of this repository in your own account.
2. **Sync the branches.** This will ensure that your copy of the repository is up-to-date with the latest changes from the https://github.com/MisterVVP/a2a-cpp repository.
3. **Work on your forked repository's feature branch.** This is where you will make your changes to the code.
4. **Commit your updates on your forked repository's feature branch.** This will save your changes to your copy of the repository.
5. **Submit a pull request to the https://github.com/MisterVVP/a2a-cpp repository's main branch.** This will request that your changes be merged into the https://github.com/MisterVVP/a2a-cpp repository.

Here are some additional things to keep in mind during the process:

- **Please follow guideline defined in [AGENTS.md](AGENTS.md).**.
- **Be patient.** It may take some time for your pull request to be reviewed and merged.

## AI-assisted contributions

The use of generative AI tools is permitted. Contributors remain fully responsible for every change they submit, regardless of how it was produced.

### Disclosure

Every pull request must disclose whether its committed code, tests, documentation, configuration, or other substantive content was:

- written by a human;
- generated by an AI agent; or
- produced through a mixture of human and AI-agent authorship.

AI usage must be disclosed when generated output is included in the submitted changes. Using AI only for research, explanations, review feedback, or brainstorming does not make the pull request AI-generated when no generated output is included.

### Labels

The following labels describe authorship and may be combined:

- `human`: the pull request contains substantive content written by a human.
- `AI agent`: the pull request contains substantive content generated by an AI agent.
- Other AI-tool labels will be introduced when needed.

Examples:

- A fully human-written pull request receives `human`.
- A pull request generated entirely by an AI agent receives `AI agent`.
- A pull request containing both human-written and AI-generated implementation receives both `human` and `AI agent`.

Prompting an AI tool, reviewing generated changes, applying formatting, resolving merge conflicts, or making minor mechanical edits does not by itself qualify a pull request for the `human` label.

Maintainers may correct authorship labels when the pull request description or review discussion indicates that they are inaccurate.

### Contributor responsibility

Contributors submitting AI-generated or AI-assisted changes must:

- understand and be able to explain the submitted changes;
- review generated output for correctness, security, licensing, and unintended modifications;
- verify that generated code does not contain confidential or improperly copied material;
- satisfy the same testing, formatting, linting, documentation, performance, and TCK requirements as any other contribution;
- accurately report which validation commands were executed and their results; and
- address review feedback rather than relying on generated output without verification.

AI-generated contributions are evaluated by the same quality standards as human-written contributions.
